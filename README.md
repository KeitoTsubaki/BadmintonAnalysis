# バドミントンの試合分析システム

バドミントンの試合動画から選手を検出し、コートを真上から見た位置に変換して、選手の位置・移動速度・移動距離を分析するシステムです。

<img src="./samples/video_capture1.jpg" alt="分析結果を重ねた試合動画" width="700">

デモ動画：https://youtu.be/wlUCjUT-T0o

- 画面左に、真上から見たコート上の選手の位置を表示します。
- 画面左のコートと選手の足元に、移動速度を表示します。足元のバーは速度に応じて長さが変わります。
- 画面左のコートに、移動方向（角度）を表示します。

## 処理の流れ

```
試合動画 ──► 選手の検出 ──► 足元の座標を俯瞰座標に変換 ──► 位置・速度・距離の集計 ──► 動画とグラフを出力
            (YOLOv5)         (射影変換)
```

1. **選手の検出**：学習済みの YOLOv5（`yolov5s`）で人を検出します。観客や審判も検出されるので、コート上にいる人だけに絞り込みます。
2. **俯瞰座標への変換**：動画に映るコートの4隅とコート図の4隅を対応させて射影変換の行列を求め、選手の足元の座標を、真上から見たコート上の座標に変換します。
3. **集計と出力**：変換した座標から、位置の分布、移動速度、移動距離を計算し、動画とグラフに出力します。

## 現在の機能

### 1. 選手の検出

<img src="./samples/video_capture2.jpg" alt="選手の検出結果" width="300">

### 2. 選手の位置分布

画面左のコート上の位置を、一定の間隔で記録します。下の図は2秒間隔で記録したものです。バドミントンではショットを打つたびにコートの中央へ戻るので、中央付近に点が集まっています。

<img src="./samples/plot.jpg" alt="選手の位置分布" width="200">

### 3. 移動速度の計測

コート上の位置座標から、指定したフレーム数ごとに移動速度を計算します。

$$speed = \frac{\text{現在の位置座標} - \text{指定フレーム数前の位置座標}}{\text{指定フレーム数}/FPS}$$

下のグラフは、指定フレーム数 30、FPS 30 のときの移動速度の時系列です。青が手前の選手、オレンジが奥の選手です。

<img src="./samples/speed.jpg" alt="移動速度の時系列グラフ" width="800">

### 4. 移動速度の傾向

移動速度を 1 m/s ごとの区間に分け、速度を計算するたびに該当する区間のカウントを増やします。下の棒グラフは、赤が手前の選手、青が奥の選手です。横軸が速度の区間、縦軸がカウントです。青の選手は、比較的速く動いていることがわかります。

<img src="./samples/speed_bar.jpg" alt="移動速度の分布" width="400">

### 5. 総移動距離の計測

コート上の位置座標から移動距離を計算し、指定したフレーム数ごとに足し合わせます。下の図は移動距離の累積で、オレンジが奥の選手、青が手前の選手です。オレンジの選手の方が多く動いていることがわかります。

<img src="./samples/total_movement.jpg" alt="総移動距離の推移" width="400">

## 使用技術

- YOLOv5（PyTorch Hub）
- OpenCV（射影変換、描画）
- ffmpeg-python（動画の出力）
- Matplotlib（グラフ）

## リポジトリ構成

```
BadmintonAnalysis/
├── main.py        # 分析の本体（動画の読み込み、座標変換、集計、出力）
├── detection.py   # YOLOv5 による選手の検出
├── analysis.py    # グラフと位置分布の画像の作成
└── samples/       # README 用の画像
```
